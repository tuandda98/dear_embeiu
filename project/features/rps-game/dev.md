## Backend (2026-09-13)

### Firestore rules — `firestore.rules` (khối `couples/{coupleId}`, sau `careMessages`)
- 3 helper mới đặt trong khối couples: `rpsPresenceTouchesOnlyOwnKey()` (presence `is map`, `diff(resource.presence).affectedKeys().hasOnly([uid])`, value của mình phải `is timestamp`; create so với `{}`), `rpsStartedAtUnchanged()`, `rpsStatusTransitionAllowed()`.
- `match /games/{gameId}`: read=member · create=member, `hasOnly [type, createdBy, status, createdAt, presence, rematchOf, updatedAt]`, `type=='rps'`, `createdBy==uid`, `status=='invited'`, `createdAt==request.time`, presence chỉ key mình, `rematchOf` non-empty string nếu có · update=member, `hasOnly` thêm `startedAt/cancelledBy/result/finishedAt` (để heartbeat presence trên ván đã finished không vỡ hasOnly), bất biến `type/createdBy/createdAt/rematchOf/result/finishedAt` (so qua `.get('x', null)`), `cancelledBy` nếu có phải == uid; transition: cùng status (startedAt không đổi) | `invited→playing` (chưa có startedAt, `startedAt==request.time`) | `invited→cancelled` (chỉ createdBy) | `invited→expired` (`createdAt < request.time - duration.value(10,'m')`) · delete=false.
- `match /games/{gameId}/moves/{uid}`: read own luôn, read người kia chỉ khi cha `status=='finished'` (get() cha) · create chỉ chủ, `hasOnly [choice, createdAt]`, choice ∈ rock/paper/scissors, `createdAt==request.time`, cha `status=='playing'` + `startedAt is timestamp` + `request.time < startedAt + duration.value(7,'s')` · update/delete=false.
- Additive hoàn toàn (collection mới); không đụng rule khác.
